# 🦀🪼🫧 FRIAS R Project : A reproducible workflow to generate a global database of FReshwater Invasive and Alien Species


## **What is this workflow all about?**

* Automated R Pipeline: It is an open-source, reproducible R workflow for global freshwater invasive and alien species data.
* Multi-Source Integration: It aggregates data from 94 sources (36 online databases, 48 scientific papers, and 10 technical reports).
* Taxonomic Harmonization: It standardizes species names and links them to unique GBIF IDs using Darwin Core standards.
* Habitat Filtering: It uses a custom check_habitat() function to automatically select freshwater organisms.
* Term Standardization: It harmonizes 9 key variables using translation tables (CBD introduction pathways, EICAT 1–5 impact scale, ISO3 codes).
* Data Deduplication: It cleans and colapses over 10,000 duplicate records into a 27-field schema.
* Global Database Output: It builds a dataset covering 3,537 unique species and 7,505 species-country-year records.
* FAIR Principles: It ensures full transparency, reusability, and end-to-end traceability.
* Policy Support: It provides data to track global goals, such as Target 6 of the Kunming-Montreal Global Biodiversity Framework.

## 🚀 Getting Started

### Prerequisites
- [R](https://www.r-project.org/) (Latest version recommended)
- [RStudio](https://posit.co/download/rstudio-ide/)

### Installing the R Package
To install the package from this repository, you can use `devtools`:

```r
# Install devtools if not already installed
install.packages("devtools")

# Install the FRIAS package from the local directory
devtools::install("path/to/FRIASpackage")
```

## 📂 Repository Structure

- `R/`: Source code for the `FRIASpackage`.
- `InputFiles/`: Raw data used for the analysis.
- `OutputFiles/`: Processed data and results generated by the scripts.
- `Figures/` & `Figures paper/`: Visualizations and plots for the publication.
- `TablesToStandardize/`: Working files for data cleaning and standardization.
- `*.R`: Analysis scripts (e.g., `Completeness_FRIAS.R`, `GBIF_NativeRange.R`).
- `world.geojson`: Geographic boundaries for spatial mapping.


## 📊 Analysis Workflow

The analysis follows these main steps:
1. **Data Cleaning:** Standardizing tables in `TablesToStandardize/`.
2. **Completeness Analysis:** Using `Completeness_FRIAS.R` to evaluate missing data before and after processing.
3. **Geographic Bias:** Assessing over/under-representation using `over_subrepresentation_geographicbias.r`.
4. **GBIF Integration:** Fetching and analyzing native ranges via `GBIF_NativeRange.R`.
